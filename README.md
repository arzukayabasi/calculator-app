# calculator-app
A modern calculator built with HTML, Tailwind CSS, and JavaScript.
This project is a sleek and functional calculator application developed using modern web technologies.

## Technologies Used
- **HTML5**: Structural framework.
- **Tailwind CSS**: Design and styling.
- **JavaScript**: Calculation logic and interactive features.

## About
This project is a calculator designed to reinforce web development fundamentals. It performs basic mathematical operations and features a user-friendly interface with smooth animations.
